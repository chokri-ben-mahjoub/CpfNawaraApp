L'application fonctionne sans Internet. Internet n'est utile que pour travailler en entreprise (partage des données entre appareils).

2Installer sur Android

  1. Copiez Android/PuitsTrack.apk sur le téléphone (câble USB, clé OTG, ou envoi par e-mail / WhatsApp).
  2. Sur le téléphone, ouvrez le fichier (application Fichiers › Téléchargements).
  3. Si Android bloque : touchez Paramètres › autorisez « Installer des applis inconnues » pour l'application Fichiers, puis revenez.
  4. Touchez Installer, puis Ouvrir.

Android 7 ou plus récent. Pour le scan du QR code, les services Google Play doivent être présents.

3Installer sur Windows

  1. Double-cliquez sur Windows/PuitsTrack-Setup.exe.
  2. Si Windows affiche « Windows a protégé votre ordinateur » : cliquez Informations complémentaires › Exécuter quand même.
  3. Suivez l'assistant (aucun droit administrateur nécessaire). Un raccourci est créé sur le bureau et dans le menu Démarrer.

Désinstallation : Paramètres Windows › Applications › PuitsTrack.

4Premier lancement : choisir le mode

Mode « Personnel » (le plus simple)

Aucun compte, aucun réseau : les données restent sur l'appareil. Saisir le nom et le service, puis créer un code à 4 chiffres. Pensez aux sauvegardes (Réglages › Sauvegarde).

Mode entreprise (données partagées entre téléphones, PC et web)

Rien à configurer. Pas de console, pas de fichier à copier : tout se fait dans l'application. Les données de chaque entreprise sont séparées et invisibles pour les autres entreprises.

Le responsable (une seule fois) :

  1. Premier lancement › Créer mon entreprise.
  2. Saisir le code d'activation reçu avec l'achat de PuitsTrack (ex. ABCD-EFGH), le nom de l'entreprise, son nom, son e-mail et un mot de passe › Créer l'entreprise. Il en devient l'administrateur.

Ajouter une personne :

  1. L'administrateur ouvre Administration › Utilisateurs › bouton Inviter, choisit le rôle (ingénieur, opérateur, lecteur ou admin) › Créer le code d'invitation.
  2. Il envoie le code (ex. ABCD-EFGH) par message avec Partager, ou fait scanner le QR code affiché.
  3. La personne installe PuitsTrack › Rejoindre mon entreprise › saisit le code (ou le scanne) › son nom, son e-mail, un mot de passe › Rejoindre.

Un code sert une seule fois et reste valable 7 jours. L'administrateur peut aussi créer le compte lui-même (Utilisateurs › Ajouter), le désactiver ou le retirer à tout moment.

Autre appareil de la même personne : premier lancement › J'ai déjà un compte › e-mail et mot de passe : l'entreprise et ses données sont retrouvées automatiquement.

5Version web (facultatif)

Le plus simple : ouvrir puitstrack.web.app dans le navigateur et se connecter avec son compte. Sinon, décompresser Web/PuitsTrack-web.zip sur un hébergement HTTPS de l'entreprise. L'application s'ouvre ensuite dans le navigateur, et aussi hors ligne après la première visite. Le navigateur peut proposer « Installer l'application ».

6Mises à jour

Installer simplement la nouvelle version par-dessus l'ancienne (nouvel APK ou nouveau Setup) : les données sont conservées. Faire une sauvegarde avant, par précaution (Réglages › Sauvegarde).
